// projects

Two systems, two different problems.

Sign Language Detection System
Python TensorFlow OpenCV MediaPipe
  • Captured live video with OpenCV and used MediaPipe to detect hand, face, and body landmarks frame by frame.
  • Extracted spatial key points from those landmarks and trained a TensorFlow LSTM/Sequential model to classify dynamic gestures over time, not just static poses.
  • Overlaid predictions directly on the live webcam feed, so gestures are interpreted as they happen.
  • Built with one goal: make communication more accessible for speech and hearing-impaired individuals.
→ the hand-tracking visual in the hero is a nod to this project's actual landmark output.
Railway Reservation System
Java HTML/CSS/JS MySQL
  • Built a full-stack reservation platform with Java on the back end and HTML/CSS/JS on the front end.
  • Implemented user registration, login, train search, ticket booking, and cancellation as complete end-to-end flows.
  • Connected the app to a MySQL database to persist passenger and train details.
  • Handled seat availability updates transactionally after every booking or cancellation, so the data never drifts from reality.
